# OUC 2026年多源遥感学习小组

欢迎来到中国海洋大学计算机学院2026年多源遥感学习小组，请关注后续信息的更新。

感兴趣的同学可以联系高峰老师加群，自愿参加各个学习环节、自愿每周打卡。有问题可以随时在群里提问，想加入学习可以给老师发邮件：gaofeng@ouc.edu.cn 。

# 🎉 1、介绍

本小组为专门为本科生设计的科研启蒙项目，每年一期，针对具有强烈科研兴趣、出色学习能力的低年级本科生；给学生提供科研培训，参与前沿的研究项目。

英雄不问出处：不限制专业、基础、排名，之前小组培养的学生分别来自计算机学院、计算机学院中英合作办学、电子学院、海德学院等。我们组指导本科生不需要特别强的能力，最后做的好不好，跟个人信息与投入有关。

学习分为 **两阶段** 培养：

## 🎯 **第一阶段：** 基础知识学习

每周一布置学习任务，在博客里写学习报告，群里打卡， **周五晚上22：00截止** 。 周日傍晚（不定期），安排线下交流，老师强化介绍知识点。

> 学习内容包括：DNN、CNN、GAN 等，应用实例包括计算机视觉的图像分类、目标检测、图像生成等，帮助学员了解、理解、掌握深度学习的基础和前沿算法，并拥有深度学习算法实战技能。
> 结合网络上最新资料，学习内容也在不断更新中。 **学习时间进度上不做要求，学的慢的同学可以两周一章，学的快的同学也可以跳着学。**

学习打卡完成度较好，可以联系老师申请结业汇报，包含至少4篇研究工作的详细阅读与技术细节梳理。其中1篇来自多源遥感图像分类，3篇可自主从互联网上搜索最新发表的重要论文。B站搜索：GrokCV，可以看汇报视频示例。

## 🎯 **第二阶段：** 复现高光谱多源分类模型

培养动手编程能力，并对齐实验结果。阅读之前本科生发表的论文，探索是如何创新并写作的。

有其它问题，我们随时在群里沟通，让我们愉快的开始吧！

# 🧩 3、一些说明

**本科生现状：** 每周学习任务多，集中时间少。期末考试、课程项目要占据大量时间。 

>  **应对策略：**学习整体会持续一年的时间，可以慢慢学习，慢慢积
>
>  累，不用着急，随时和老师、研究生学长沟通。如果学习过程中发现不喜欢，可以随时放弃打卡，不要有任何心理压力或者不好意思

**老师现状：** 要负责教学、指导研究生、忙活项目、照顾家庭等。项目有时压力比较大，忙起来完全没有时间看论文和指导学生，希望互相理解。

> **应对策略：** 如果没有及时回应，你可以多催促我 （尽管大多时候催了也没啥用，尴尬ing ...  ）。但是这种是非常好的，我不会觉得烦，念念不忘必有回响。说明你对于科研非常上心，我也会优先给你分配资源

**回归初心：** 建立这个小组，初心是给大家进行 **科研科普** 。考虑到很多同学将来会读研读博，通过和老师、研究生学长交流，可以提前了解 *“科研是怎样的，论文是如何写出来的，研究生在过怎样的生活，自己将来喜不喜欢这样的日子。”* 但老师精力有限，可能照顾不到太多同学，**因此在跟我们组学习的同时，也可以联系其他老师跟着学习，不要有任何心理负担。**

**持续改进：** 前面两年踩的坑，今年会尽量避免。AI在进步，效率在提高，我对年轻人有信心。我们是合作关系，有问题请大家多批评，期待在大家一起努力持续改进，未来会更好。
